# web-rpa

웹에서 하는 반복 작업을 한 번 녹화해 "레시피"로 만들고, 엑셀 행마다 같은 작업을 자동으로 반복하는 Windows용 로컬 RPA 도구입니다.
조회·입력·다운로드·PDF 저장·화면 캡처·값 읽기를 행마다 하고, 결과를 엑셀과 리포트로 남깁니다.

- 녹화: 평소처럼 브라우저에서 작업하면 클릭·입력·선택·다운로드·파일 첨부·알림창 응답이 스텝으로 기록됩니다. 팝업 창과 iframe 안의 동작도 기록합니다.
- 반복: 입력값을 엑셀 열로 바꾸면 엑셀 행마다 실행합니다. 실패한 행은 화면을 남기고 다음 행으로 넘어갑니다. 한 행 안에서도 화면 목록의 항목마다(표의 행마다), N번·조건이 맞는 동안, 다음 쪽이 없을 때까지 반복할 수 있습니다.
- 편집: 스텝 트리(전역 번호 `#3.2`)·찾기·여러 개 골라 한꺼번에 묶기, 문장으로 고르는 조건, 입력값 정리, 변수 이름 바꾸기. 모든 화면의 AI 도우미에게 말로 고쳐 달라고 할 수도 있습니다.
- 비밀값: 비밀번호는 레시피에 남기지 않고, 원하면 이 PC(Windows 계정)에만 암호화해 저장합니다.
- 결과: 행별 성공/실패, 읽은 값, 받은 파일, 실패 화면, 결과 엑셀, 실행 기록, (선택) 실행 화면 영상.
- 브라우저: PC에 설치된 Edge·Chrome·Brave(또는 Playwright Chromium)를 씁니다. 모든 처리는 이 PC 안에서 합니다.
- 진행 세트·허브: 레시피를 예시 입력·설명과 함께 세트 파일(.wrset)로 묶어 나누고, [공개 허브](https://tak002.github.io/web-rpa-hub/)에서 다른 사람의 세트를 가져옵니다.

## 설치와 실행

필요한 것: Windows 10/11 (64비트), Edge 또는 Chrome. Node.js 는 설치 파일에 들어 있습니다.

- **설치 파일** `web-rpa-setup-<버전>.exe` — 관리자 권한 없이 `%LOCALAPPDATA%\Programs\web-rpa` 에 설치하고 시작 메뉴(선택하면 바탕화면)에 바로가기를 만듭니다. 바로가기를 누르면 화면이 브라우저에 열리고, 함께 뜨는 검은 창을 닫으면 멈춥니다. 이미 실행 중이면 화면만 엽니다. 제거는 Windows 설정 → 앱에서 합니다.
- **압축본** `web-rpa-<버전>-win-x64.zip` — 원하는 폴더에 풀고 `web-rpa.cmd` 를 실행합니다.
- 두 방식 모두 작업 데이터(레시피·실행 결과·브라우저 프로필·설정)는 `%LOCALAPPDATA%\web-rpa` 에 저장되고, 다시 설치하거나 제거해도 남습니다.
- 설치 파일은 코드 서명이 되어 있지 않아 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. "추가 정보 → 실행"을 누르면 설치됩니다.

소스에서 실행하려면 [Node.js](https://nodejs.org/) 20 이상을 설치하고 `start.cmd` 를 실행합니다(처음에 의존성을 설치하고 http://127.0.0.1:4800 을 엽니다. 작업 데이터는 `workspace\`).
설치 파일 만들기: [Inno Setup 6](https://jrsoftware.org/isinfo.php) 을 설치한 뒤 `node scripts\package-win.mjs --installer --smoke` (결과 `dist\`, 만든 파일을 실제로 설치·실행·제거해 확인합니다).

- **브라우저**는 화면의 **설정**에서 고릅니다: 자동(Edge → Chrome → Brave → 내장 Chromium), Edge, Chrome, Brave, 내장 Chromium, 직접 지정(Chromium 계열 실행 파일). 설치 여부는 자동으로 감지하고 "시험 실행"으로 버전을 확인할 수 있습니다.
- **프로필**은 브라우저마다 따로 둡니다(`workspace\profiles\<브라우저>`). 녹화·실행·AI 관찰이 같은 프로필을 쓰므로 녹화 브라우저에서 로그인해 두면 실행 때도 유지됩니다(사이트가 세션을 유지하는 동안).
- 녹화·실행 브라우저는 서버가 도는 PC 화면에 뜹니다. 서버를 서비스(세션 0)로 띄우면 브라우저 창이 보이지 않으니, 로그인한 사용자 세션에서 실행하세요(`run-server.cmd`).

## 쓰는 순서

1. **녹화** — 이름과 시작 주소를 넣고 녹화를 시작합니다. 열린 브라우저에서 평소처럼 작업한 뒤 "녹화 종료하고 저장". 로그인부터 녹화했다면 편집기 맨 위에 "로그인 단계가 있습니다" 안내가 뜹니다 — [로그인 화면일 때만 하도록 묶기] 를 누르면 2행부터(이미 로그인된 뒤) 로그인 스텝을 건너뜁니다.
2. **편집** — 입력값을 엑셀 열로 바꿉니다([입력값 정리] 한 창에서, 또는 "엑셀 첫 행으로 자동 연결"). 필요하면 값 읽기·대기·PDF 저장·반복·조건 분기 스텝을 더합니다.
3. **실행** — 엑셀(xlsx·csv)을 넣고 실행합니다. 비밀값은 칸에 넣고, [이 PC 에 저장] 을 켜면 다음부터 묻지 않습니다.
4. **리포트** — 행별 결과, 읽은 값, 저장 파일, 실패 화면, 결과 엑셀(`results.xlsx`), 실행 기록. 실패 행의 오류는 쉬운 첫 문장으로 보이고 시도한 후보 목록은 [자세히] 에 접혀 있습니다. 머리의 [편집]·[▶ 다시 실행] 으로 바로 고치고 다시 돌립니다.

## 편집기

- **스텝 트리**: 반복·분기의 안쪽 스텝은 부모 아래에 들여 보이고 번호가 `#3.1`·`#3.2.1` 처럼 붙습니다(실행 기록·AI 와 같은 번호). 어디서도 부르지 않는 블록은 맨 아래 "쓰이지 않는 블록" 에 모입니다.
- **찾기·거르기**: 글자 또는 번호(`#3` 은 그 스텝과 안쪽 전부), 스텝 종류, 고칠 점 있음·변수를 쓰는 스텝·꺼 둔 스텝. [찾은 스텝 모두 고르기].
- **여러 개 고르기**: 스텝 머리의 체크로 고르면 아래에 일괄 막대가 붙습니다 — 삭제·끄기·켜기·[반복으로 묶기]·[목록의 항목마다로 묶기]·[조건부로 만들기]·[✦ AI 에게]. 묶은 것은 [풀기] 로 되돌립니다.
- **반복**
  - *목록의 항목마다*: 표의 행처럼 화면에서 되풀이되는 항목마다 안의 스텝을 실행합니다. 녹화한 표 칸 스텝을 골라 묶으면 그 칸이 있는 **표의 행 전체**를 목록으로 정하고, 안의 스텝을 "항목 안에서 찾기" 로 바꿉니다(행마다 그 행의 값을 읽음). 목록은 "기존 스텝 요소에서 고르기"(행 전체가 먼저)·CSS 선택자·[AI 에게 목록 찾기 맡기기] 로도 정합니다. 항목마다 상세 화면에 들어갔다 오면 "항목마다 끝나면 뒤로 가기".
  - *반복*: N번 / 조건이 참인 동안 / 조건이 참이 될 때까지 / **쪽 넘기기 — 다음 쪽이 없을 때까지**(지금 쪽을 처리하고, 두 번째 반복부터 먼저 "다음" 을 누르고, "다음" 이 없는 마지막 쪽까지). 최대 반복 횟수(기본 100)에 닿으면 경고만 남기고 다음 스텝으로 갑니다.
  - 틀리기 쉬운 구조는 바로 알려 줍니다: 목록 안인데 항목 안에서 찾지 않아 같은 값을 되풀이하는 스텝("항목마다 같은 요소" 배지 + [항목 안에서 찾기로 바꾸기], 실행 전 고칠 점), 몸통 끝에서 "다음" 을 눌러 마지막 쪽을 빠뜨리는 반복("마지막 쪽 빠짐" 배지 + [쪽 넘기기로 바꾸기]), 항목이 1개뿐인 목록.
- **조건**: `만약 [무엇이] [어떠하면] [값]` 으로 고릅니다 — 화면 글자·주소·알림창 문구·요소(있으면·없으면·보이면·글자·개수)·값(`{{금액}} ≥ 10000`, `{{상태}}` 에 "폐업" 포함, 비어 있으면, 정규식). [＋ 그리고]·[＋ 또는] 로 묶고 미리보기 문장으로 확인합니다. 대기·확인·분기·반복에 모두 씁니다.
- **변수**: 이름을 바꾸면 쓰는 곳이 함께 바뀌고, 쓰는 곳 단추로 그 스텝에 갑니다. 안 쓰는 변수 표시, 지울 때 쓰는 곳 경고. 종류는 엑셀 열·고정값·실행할 때 입력·비밀값(기본값 칸 없음).
- **입력값 정리**: 녹화한 입력을 한 표에서 보고 칸마다 그대로/엑셀 열/실행 때 입력/비밀 을 골라 [모두 적용].
- 값 칸에서 `{{` 를 치면 변수·값 읽기 이름·`{{row}}`·날짜 토큰·반복 안이면 `{{item.text}}`·`{{loop.index}}` 를 고를 수 있습니다.

## AI 도우미 (선택, OpenRouter)

모든 화면의 **✦ AI 도우미**(편집기·실행·리포트 머리, 위쪽 막대의 "✦ AI 대화")로 패널을 열어 레시피를 대화로 고칩니다. 예: "입력값들을 엑셀 열로 바꿔 줘", "결과 표의 행마다 금액을 읽어 줘", "다음 쪽이 없을 때까지 돌려 줘".

- **대화는 레시피마다 저장**됩니다(`workspace\ai\<레시피 id>\thread.json`). 화면을 옮기거나 서버를 다시 켜도 대화·적용 전 제안·입력 중 글이 그대로이고, 편집·실행·리포트 화면은 그 레시피의 대화를 엽니다. 30일 지난 대화는 지웁니다. 실행 화면에서 다른 레시피를 고르면 대화가 바뀐다는 안내와 [돌아가기] 가, 편집기에 열린 레시피와 대화 레시피가 다르면 경고 줄이 뜨고 보내기·적용 전에 한 번 묻습니다.
- **맥락**: 지금 화면, 고른·펼친 스텝(`#3.1`), 올린 엑셀의 열·첫 행, 보고 있는 실행·실패 행, 레시피 개요, 지난 AI 답 이후 직접 바꾼 것을 요청과 함께 보냅니다(패널 입력창 위 "함께 보내는 맥락"). 스텝·실패 행·일괄 막대의 **[✦ AI 에게]** 는 그 맥락과 초안을 입력창에 넣습니다(바로 보내지 않음).
- **메모**: AI 가 알아낸 사이트 사실(늦게 뜨는 화면, 입력 형식 등)을 레시피 메모(`notes.md`)에 남기고 다음 요청에 함께 보냅니다. 패널의 [메모] 에서 보고 고칩니다. [대화 지우기] 를 해도 메모는 남습니다.
- 답은 글자가 오는 대로 보이고, 도구를 쓰는 동안 진행 줄이 보입니다. 뜻이 둘이면 선택지 단추로 묻습니다. 말풍선마다 이번 요청 비용, 위쪽에 누적 비용.
- OpenRouter 키와 모델을 패널의 [설정]에서 넣습니다(`workspace\settings.json`, 화면에는 끝 4자리만). 환경 변수 `OPENROUTER_API_KEY` 도 됩니다.
- 필요하면 숨긴 브라우저로 레시피를 특정 스텝까지 실행해 화면 요소 목록을 보고(관찰 브라우저는 대화마다 열어 두고 5분 쉬면 닫음), 참조 번호로 새 요소·목록·항목 안 요소를 지정하고, 1~2행을 시험 실행해 봅니다. 출력 스텝(PDF·다운로드·첨부)은 건너뛰고, "제출·신고·결제·삭제·발송"류 버튼은 허용하지 않으면 누르지 않습니다.
- AI 의 변경은 사본에만 합니다. 제안 카드(`#8 추가: …`)를 보고 편집기에서는 [적용] 후 [저장], 실행·리포트 화면에서는 [적용하고 저장] 합니다. 이어서 요청하면 대기 중인 제안 위에서 고칩니다.
- **데이터 전송 고지**: AI 도우미를 쓰면 레시피 내용(녹화된 입력값 포함)과 관찰한 화면 요소 목록이 OpenRouter 와 선택한 모델 제공사로 전송됩니다. 비밀값과 비밀 칸의 녹화값은 `••••` 로 가려 보내지 않습니다. 개인정보·고객 정보가 담긴 레시피에는 쓰지 마세요. AI 도우미를 쓰지 않으면 외부로 아무것도 보내지 않습니다.

## 비밀값 (이 PC 에 저장)

- 녹화한 비밀번호 칸은 "비밀값" 변수(`prompt` + `secret`)가 되고 녹화한 값은 남기지 않습니다. 레시피 파일·세트·실행 기록·AI 로 가는 내용에 비밀값이 들어가지 않습니다.
- 실행 화면의 비밀값 칸에서 **[이 PC 에 저장]** 을 켜고 실행하면 그 값을 Windows DPAPI(지금 Windows 계정, CurrentUser)로 암호화해 `workspace\secrets.json` 에 둡니다. 다음 실행부터는 "●●●● 저장됨 · 바꾸기 · 지우기" 로 보이고 묻지 않습니다. 다른 PC·다른 계정에서는 풀 수 없어 다시 입력해야 합니다. 변수 탭에도 "●●●● 이 PC 에 저장됨" 이 보입니다.
- 암호화는 PowerShell 에 표준 입력으로 값을 넘겨 합니다(명령줄에 비밀값을 쓰지 않음). Windows 가 아니면 저장 기능만 꺼집니다. AI 의 화면 관찰·시험 실행도 저장된 값을 쓰지만 AI 에게 값은 보이지 않습니다.

## 진행 세트(.wrset)와 허브

진행 세트는 레시피를 다른 사람이 바로 쓸 수 있게 묶은 zip 파일(.wrset)입니다.

| 파일 | 내용 |
|---|---|
| `manifest.json` | id(`게시자/이름`)·이름·버전·설명·만든 사람·라이선스(기본 CC0-1.0)·태그, 필요한 web-rpa 버전 범위, 접속 사이트와 하는 일, 엑셀 열 설명·예, 실행 때 넣는 값, 위험 표시, 실행 간격 |
| `recipe.json` | 정리한 레시피 (녹화 원본 값·받은 파일 이름·알림창 문구·주소의 쿼리·첨부 경로·id·시각 제거) |
| `README.md` | 설명 |
| `input/sample.csv` | 예시 입력 1~5행 (UTF-8 BOM, 공개 정보나 지어낸 값만) |
| `expected.json` (선택) | 예시 입력으로 실행했을 때의 기대 결과 `{ totals?, rows: { "*": { status, values: { 이름: { equals \| contains \| regex } }, files: [{ glob, type }] }, "<첫 열 값>": { … } } }` |
| `CHANGELOG.md`, `media/*.png·jpg`(500KB 이하), `input/template.xlsx` (선택) | 변경 기록, 그림, 엑셀 양식(매크로·외부 연결 금지) |

**가져오기** — 상단 **허브** 화면에서 세트를 찾아(이름·설명·태그·사이트·엑셀 열) 상세를 열고 [가져오기]를 누릅니다. web-rpa 가 세트 파일을 내려받아 허브 목록의 sha256 과 같은지, 지금 버전에서 도는지 확인하고 "이 세트는 dart.fss.or.kr 에만 접속합니다. 파일을 저장합니다." 처럼 하는 일을 보여 줍니다. [설치]하면 레시피와 예시 입력이 추가되고, [예시로 실행]으로 바로 돌려 볼 수 있습니다. 받아 둔 파일은 [세트 파일 가져오기]로 설치합니다. 같은 세트를 다시 설치하면 그 레시피를 새 버전으로 바꾸고 이전 레시피는 작업 폴더 `trash` 에 둡니다.

**설치한 세트의 안전장치** — 세트로 설치한 레시피는 실행할 때 세트가 밝힌 사이트 밖으로 페이지(업무 탭·팝업)가 이동하지 못하게 막고(그 행은 실패로 기록), 세트가 정한 행 사이 최소 간격을 쉬며, 한 번에 실행할 행 수를 넘으면 멈추고 이어서 할 행을 알려 줍니다. 제한은 레시피의 `origin` 에 있습니다(직접 녹화한 레시피에는 없음).

**내보내기** — 편집기의 [세트로 내보내기]가 정보(설명·만든 사람·사이트에서 하는 일·엑셀 열 설명) → 정리 검토(남은 입력값마다 그대로 둠/지우기) → 예시 입력 → 기대 결과(선택, 지난 실행으로 초안) → 검사·내려받기 순서로 안내합니다. 주민등록번호·휴대전화·이메일·카드번호로 보이는 값이 있으면 내보낼 수 없습니다. 공개 허브에 올리는 방법은 [허브 저장소의 CONTRIBUTING](https://github.com/Tak002/web-rpa-hub/blob/main/CONTRIBUTING.md) 을 보세요.

**허브 주소** — 설정 → 허브에서 바꾸거나 더합니다(https 만, 기본값 `https://tak002.github.io/web-rpa-hub/index.json`). 허브 목록에는 세트 파일마다 sha256 이 있고, 내려받은 파일이 다르면 설치하지 않습니다.

## 명령줄

설치본은 `web-rpa.cmd <명령>`, 소스에서는 `node src\cli.js <명령>` 으로 씁니다. 작업 폴더는 `--workspace 폴더`(기본 `%LOCALAPPDATA%\web-rpa`).

```cmd
web-rpa.cmd set lint 세트폴더                 :: 세트 검사 (허브 CI 와 같은 규칙, 오류면 종료 코드 1)
web-rpa.cmd set pack 세트폴더 -o 파일.wrset    :: 풀어 둔 폴더를 묶기 (같은 내용이면 같은 sha256)
web-rpa.cmd set unpack 파일.wrset -o 세트폴더  :: 풀기
web-rpa.cmd set test 파일.wrset --param 비밀번호=…  :: 임시 작업 폴더에 설치해 예시 입력을 숨김 실행하고 expected.json 과 비교 (--headed 로 창 표시)
web-rpa.cmd set install 파일.wrset            :: 작업 폴더에 설치
web-rpa.cmd hub list                          :: 허브의 세트 목록
web-rpa.cmd hub install tak002/dart-latest-periodic-report[@1.0.0]  :: 내려받아 sha256·버전 범위 확인 후 설치
```

## 레시피 형식 (요약)

```jsonc
{
  "schemaVersion": 1, "id": "…", "name": "…", "startUrl": "https://…",
  "variables": [{ "id": "상호", "name": "상호", "source": { "kind": "excel", "column": "상호" } }],
  "entryBlock": "main",
  "blocks": { "main": [ { "id": "s1", "type": "navigate", "url": "…" }, { "id": "s2", "type": "input", "target": { … }, "value": "{{상호}}" } ] },
  "loop": { "onRowError": "skip" }
}
```

- 스텝 종류: `navigate` `click` `dblclick` `input` `select` `check` `keypress` `wait` `sleep` `extract` `assert` `branch` `repeat` `forEach` `dialog` `pdf` `screenshot` `download` `upload` `pause` `closeTab`
- 스텝 공통 필드: `optional`(대상이 없으면 건너뜀), `onError: "continue"`, `attempts`(총 시도 횟수), `timeoutMs`, `disabled`
- `branch { condition, then, else? }` 는 `then`/`else` 블록을 실행한 뒤 다음 스텝으로 돌아옵니다.
- `repeat { body, times | while | until, maxIterations? }` — `times`·`while`(반복 전 검사)·`until`(반복 뒤 검사) 중 하나, `maxIterations` 기본 100(1–1000, 닿으면 경고만). 쪽 넘기기는 `until: not exists(다음)` + 몸통 맨 앞 `branch {{loop.index}} > 1 → "다음" 클릭` 입니다.
- `forEach { items, body, maxItems?, restore? }` — `items` 는 여러 요소에 맞는 대상(예: `#result > tbody > tr:has(> td)`), 시작할 때 세고 항목마다 다시 찾습니다. 몸통 스텝의 `target` 에 `"within": "item"` 이 있으면 지금 항목 안에서 찾습니다(후보는 `:scope > td:nth-of-type(4)`·`./td[4]` 같은 항목 기준 선택자). `restore: "back"` 은 항목마다 원래 목록 화면으로 돌아옵니다. `maxItems` 기본 100.
- 반복 안의 `extract` 는 반복마다 읽은 값을 줄바꿈으로 이어 행 결과·결과 엑셀 칸에 남깁니다(반복 안에서 `{{이름}}` 은 지금 값).
- 조건(`wait`·`assert`·`branch`·`repeat`): `exists` · `textVisible` · `urlContains` · `varEquals` · `dialogContains` · `varContains` · `varCompare`(`= != > < >= <=`, 숫자·날짜·글자 순으로 비교) · `varEmpty` · `matches`(정규식) · `elementText`(`equals·contains·matches`) · `elementCount` · `not` · `all` · `any`
- 변수 종류: `excel` · `static` · `prompt`(실행 때 입력, `secret: true` 면 비밀값 — 기본값을 레시피에 두지 않음)
- 내장 토큰: `{{row}}`, `{{sys:date:YYYYMMDD}}`, `{{sys:month:-1}}`, `{{sys:quarter}}`, `{{lastDialogMessage}}`. 반복 안: `{{loop.index}}`(1부터)·`{{loop.count}}`, 목록 안: `{{item.text}}`·`{{item.index}}`·`{{item.cell:N}}`(표의 행이면 N번째 칸). 변환: `{{값|digits}}`, `|trim`, `|upper`, `|lower`, `|default:x`

```jsonc
// 결과 표의 행마다 금액 읽기 + 다음 쪽이 없을 때까지
"main":    [ { "id": "s1", "type": "navigate", "url": "…" },
             { "id": "s2", "type": "repeat", "until": { "kind": "not", "condition": { "kind": "exists", "target": { /* "다음" */ } } }, "maxIterations": 20, "body": "쪽마다" } ],
"쪽마다":  [ { "id": "s3", "type": "branch", "condition": { "kind": "varCompare", "var": "loop.index", "op": ">", "value": "1" }, "then": "다음누르기" },
             { "id": "s4", "type": "forEach", "items": { /* 표의 행 */ }, "body": "행마다" } ],
"다음누르기": [ { "id": "s5", "type": "click", "target": { /* "다음" */ } } ],
"행마다":  [ { "id": "s6", "type": "extract", "target": { "within": "item", "candidates": [ { "kind": "css", "value": ":scope > td:nth-of-type(4)", "score": 80 } ], "meta": { "label": "금액" } }, "saveAs": "금액" } ]
```

자세한 동작은 [docs/requirements.md](docs/requirements.md), 구현 방식은 [docs/design-notes.md](docs/design-notes.md) 를 보세요.

## 알려진 제한

- 화면 표시 모드의 PDF 저장은 전체 화면 캡처를 A4 로 나눈 이미지 PDF 입니다(글자 선택 불가). 숨김 실행이면 인쇄용 PDF 로 저장됩니다.
- 사이트의 `window.print()` 는 재생 중 막습니다. 출력은 PDF 스텝이 맡고, 실제 프린터 출력은 없습니다.
- 녹화 중 주소창에 직접 친 이동은 자동 기록되지 않습니다. "현재 주소로 이동" 버튼으로 넣습니다.
- 파일 첨부는 녹화되지만 첨부할 파일 경로는 편집에서 지정해야 합니다.
- 공동인증서·간편인증 같은 로그인은 자동화하지 않습니다. 녹화 브라우저에서 직접 로그인해 두거나 "사용자 확인 대기" 스텝으로 사람이 처리합니다.
- 지난번에 처리한 항목 건너뛰기는 아직 없습니다(처리할 항목을 엑셀 행으로 나열하세요). 녹화 중 "여기부터 반복" 단추, 화면에서 요소를 다시 골라 바꾸기도 없습니다 — 반복은 편집기에서 묶고, 새 요소는 AI 도우미의 화면 관찰로 지정합니다.
- "다음" 을 누른 뒤 스크립트가 잠시 뒤에 쪽을 바꾸는 사이트는 반복 조건·목록이 옛 화면을 볼 수 있습니다. "다음" 클릭 뒤에 대기(바뀐 쪽 번호 글자가 보일 때까지 등) 스텝을 두세요.
- 반복 안에서 연 팝업을 닫지 않으면 다음 항목의 (항목 안이 아닌) 스텝이 팝업에서 돕니다. 녹화하면 보통 "팝업 창 닫기" 가 남습니다.
- 0.2.0 이전 엔진(설치한 세트의 엔진 범위)은 `repeat`·`forEach`·새 조건 종류를 모릅니다.
- 비밀값 저장은 Windows 에서만 됩니다(DPAPI). AI 대화·메모는 이 PC 의 작업 폴더에만 남고 30일 지난 대화는 지워집니다(메모는 남음).
- 인증이 없는 로컬 도구입니다. 서버는 127.0.0.1 에만 열립니다. 다른 기기에서 쓰려면 VPN 등 신뢰할 수 있는 사설망 안에서만 여세요.
- 허브 목록은 아직 서명하지 않습니다. https 와 목록의 sha256 으로만 확인하므로, 믿는 허브 주소만 넣으세요.
- 세트 사이트 제한은 페이지 이동만 막습니다(그림·스크립트 같은 하위 자원과 iframe 은 막지 않음). 리디렉션으로 넘어간 경우는 넘어간 뒤 알아채 빈 페이지로 돌리고 그 행을 실패로 남깁니다. AI 도우미의 화면 관찰에는 적용하지 않습니다.
- 서버는 IP 주소나 `localhost` 로 접속한 요청만 받고, 다른 웹사이트가 보낸 요청은 거절합니다. 컴퓨터 이름(예: `mypc.tailnet.ts.net`)으로 접속하려면 `--allow-host 이름`(또는 환경 변수 `WEB_RPA_ALLOWED_HOSTS`)으로 허용해 주세요.

## 책임 있는 사용

- 자동화하려는 사이트의 이용약관과 자동 접속 정책을 지키는 것은 사용자의 책임입니다. 과도한 반복 요청으로 서비스에 부담을 주지 마세요.
- 다른 사람 명의의 계정·인증서로 로그인하거나, 권한 없는 정보에 접근하는 데 쓰지 마세요.
- 다른 사람이 만든 세트는 가져오기 전에 접속하는 사이트, 위험 표시(제출·결제, 파일 첨부 등), README 를 확인하세요. 세트를 공개할 때는 실제 고객·거래처 정보를 넣지 마세요.
- 실행 결과(`workspace\runs`)와 브라우저 프로필(`workspace\profiles`)에는 화면 내용과 로그인 쿠키가 남습니다. 공유하거나 저장소에 올리지 마세요.
